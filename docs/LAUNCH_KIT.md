## Community introduction

Title: I built an open-source way to dictate prompts inside my Mac terminal and VS Code

VozTTY adds local voice dictation directly to terminal input. It is useful when explaining context, constraints and multi-step coding tasks without switching tabs to transcribe elsewhere.

The transcript remains editable; dictation never presses Enter. The native terminal has a continuous voice-intensity history, pause/resume and a shared vocabulary file for assistant and project names. A separate VS Code extension works with existing integrated terminals.

This is an early Apple Silicon/macOS 26+ preview. It uses Apple's on-device recognition and has no VozTTY transcription backend. Proper names can still be misrecognized, and the current downloads are not notarized. I would appreciate feedback on microphone reliability, accessibility and installation.

Code and downloads: https://github.com/ricdanyalgil/VozTTY
